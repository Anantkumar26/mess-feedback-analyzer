# Mess Feedback Analyzer

## Overview
Mess Feedback Analyzer is a simple Python console application used to collect and analyze student feedback about mess food.

## Features
- Add feedback for a dish
- Give a rating from 1 to 5
- Store feedback in a text file
- View feedback
- Calculate the average rating

## Technologies Used
- Python
- Text file handling

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run `main.py`.
4. Select an option from the menu.

## Testing
Add different dishes and ratings and check whether the feedback is saved and the average rating is calculated correctly.
